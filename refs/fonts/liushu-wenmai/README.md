# 六书文脉小篆 · Liushu Wenmai Xiaozhuan

依《说文解字》公版底本整理的开源小篆字体，SIL OFL 1.1 授权，个人与商业均可免费使用。

## 这是什么

一套小篆风格字体。字形依据公有领域底本（清同治十二年即 1873 年，陈昌治刻本一系《说文解字》）自行数字化整理，未使用任何现代商业字库的字形数据。

| 项 | 说明 |
|---|---|
| 设计单位 | UPM 1000，字面框 900 × 680 |
| 当前收录 | 《说文》正篆 703 个（含重文等共 1,603 个码位） |
| 格式 | TTF（OTF / WOFF2 后续提供） |
| 风格 | 玉箸篆 |

## 当前状态

**进行中的项目，不是完成品。**

| 版本 | 覆盖 | 状态 |
|---|---|---|
| v0.8 | 703 正篆 | 可下载试用 |
| v0.9 | 540 部首 + 常用 2,000 字 | 设计中 |
| v1.0 | 6,763 字 | 规划中 |

已知限制：

- 未覆盖的字会回退到系统字体，属正常现象
- 部分生僻字放在私有使用区（PUA），需配合映射表使用
- 字形以传世《说文》为准，不保证与出土文字材料（甲骨、金文）完全一致
- 字形修长，字面率约 47%，单字展示效果最佳；整句排版建议字距设为 −0.1em

## 下载与安装

字体文件见 [Releases](https://github.com/jianyue2026/liushuwenmai-xiaozhuan/releases) 页面。

| 系统 | 安装方式 |
|---|---|
| Windows | 右键字体文件 → 安装 |
| macOS | 双击 → 字体册 → 安装字体 |
| Linux | 复制到 `~/.local/share/fonts/` 后执行 `fc-cache -f -v` |

## 在网页中使用

```css
@font-face {
  font-family: "Liushu Wenmai Xiaozhuan";
  src: url("./liushuwenmai-xiaozhuan.ttf") format("truetype");
  font-display: swap;
}

.seal {
  font-family: "Liushu Wenmai Xiaozhuan", serif;
}
```

## 字形来源

- 底本：《说文解字》大徐本（陈昌治刻本一系，公有领域），辅以小徐本
- 构件体系：《说文》540 部首归并为 312 个基础构件
- 未使用北师大《说文小篆字库》、方正小篆体、汉仪篆书等现代字库的字形数据
